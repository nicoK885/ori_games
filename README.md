# Browser Games

Eine Sammlung kleiner, direkt spielbarer Browser-Games.

## Öffentliche Struktur

```text
games/
├── ori/
│   ├── many-oris/
│   └── ori-jagd/
├── manys/
│   ├── many-mamis/
│   └── many-thierrys/
└── originals/
    ├── lumen/
    ├── sumi/
    ├── schwarm/
    └── seiten-bewohner/
```

- **Ori:** Spiele mit direktem Ori-Bezug.
- **Manys:** Figuren-Schwarmspiele auf einer gemeinsamen Mechanik.
- **Originale:** Eigenständige Spiele ohne Ori-Bezug.

Die Dateien unter `games/` sind die stabilen öffentlichen Einstiegspunkte für GitHub Pages. Bestehende technische Ordner bleiben vorerst erhalten, damit die laufenden Spiele und ihre Abhängigkeiten nicht beschädigt werden.

## GitHub Pages

Alle Links sind relativ aufgebaut. Das Repository kann deshalb später ohne Codeänderung von `ori_games` zu `browser-games` umbenannt werden.
